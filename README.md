# Digitaltwin_hospital
Managing a hospital is incredibly challenging. Patients don't arrive on a predictable schedule, there's never enough ICU beds or diagnostic equipment to go around, and someone who looks stable right now might take a turn for the worse an hour later. Most hospitals still rely on pretty straightforward queue management—either you get seen in the order you arrived, or you're assigned a priority level when you check in. The problem with this is that it assumes your urgency level stays the same, which obviously isn't how things work in practice. A patient who seemed okay initially might crash, while someone else responds well to treatment and stabilizes. We designed a framework that can actually keep up with these changes as they happen.
What we've built has three core pieces. The first is something called a patient digital twin—think of it as a mirror image of the actual patient that updates continuously based on their current state. These twins pull information from bedside monitors, lab work, medical records, and wearable sensors to stay accurate. Second, we added a scoring system inside each twin that calculates standard clinical measurements like NEWS2, SOFA, qSOFA, MEWS, and the Rothman Index. All these scores feed into one number we call the Dynamic Priority Score. Third, we created a scheduler inspired by how computer operating systems work that uses this score to reorganize queues and move resources around.
We implemented a working prototype of this system to validate the concept. The prototype includes a real-time dashboard that monitors multiple patients simultaneously, tracking vital signs and calculating priority scores continuously.
